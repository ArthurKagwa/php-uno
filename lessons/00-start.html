Lesson 00

What you need & how this works

Goal

Understand what you're about to do, so nothing later feels like magic.

What is PHP?

PHP is a language that runs on a web server. The server runs your PHP code and sends the finished page to the browser. That's why you can't just double-click a .php file. Something has to run it first.

What you need

  1. A Windows PC (Windows 10 or 11).
  2. WampServer, a free program that turns your PC into a small web server with PHP. You'll install it in Lesson 1.
  3. A code editor. We'll use VS Code, which is free.
  4. About an hour in total, spread over as many days as you like.

How the lessons work

  • Each lesson is small: one idea, a few steps, then a quick check.
  • Code boxes have a Copy button, but typing the code yourself helps you learn it.
  • Press Mark as done at the bottom of a lesson to tick it off on the lesson list.
  • Stuck? Jump to Lesson 12: Troubleshooting.

Using XAMPP instead? Everything works the same way. Just use C:\xampp\htdocs wherever these lessons say C:\wamp64\www.
