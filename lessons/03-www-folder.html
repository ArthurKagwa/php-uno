Lesson 03

The www folder & your first project

Goal

Learn the one rule behind every project: a folder in www becomes a web address.

Steps

  1. Open C:\wamp64\www. You can also left-click the tray icon and choose www directory.
  2. Create a new folder called test. Use lowercase letters and dashes, with no spaces.
  3. Open VS Code, then File → Open Folder and pick C:\wamp64\www\test.
  4. Create a new file called index.php, type the line below, and save it (Ctrl+S).
  5. In your browser, open http://localhost/test/.
test/index.php
<?php echo "It works!"; ?>

You should see

The words It works! on the page.

The rule: C:\wamp64\www\test\index.php → http://localhost/test/
Always open PHP through http://localhost/…. Double-clicking the file won't work.

Try this: make another folder called me with an index.php that echoes your name, then open http://localhost/me/.

Shortcut: every project in the next lessons is also in the projects/ folder of this repo. Download it from GitHub (Code → Download ZIP) and copy those folders into www if you get stuck.
