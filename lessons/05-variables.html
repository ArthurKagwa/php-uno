Lesson 05

Variables & echo

Goal

Learn about variables, which are labelled boxes that hold a value. In PHP, every variable name starts with $.

Steps

  1. In C:\wamp64\www, create a folder called 05-variables.
  2. Inside it, create index.php and paste in the code below. Typing it yourself is even better.
  3. Save with Ctrl+S.
  4. Open http://localhost/05-variables/ in your browser.
Save asC:\wamp64\www\05-variables\index.php
Run ithttp://localhost/05-variables/
05-variables/index.php
<?php
// Variables start with a $ sign
$name = "Arthur";
$age = 23;
$city = "Kampala";
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Variables &amp; echo</title>
</head>
<body>
    <h1>About me</h1>
    <?php
    echo "<p>My name is $name.</p>";
    echo "<p>I am $age years old.</p>";
    echo "<p>I live in $city.</p>";
    ?>
</body>
</html>

You should see

Three lines: "My name is Arthur.", "I am 23 years old.", "I live in Kampala."

Notice: inside double quotes, PHP swaps $name for its value. Text is wrapped in quotes, but numbers like 23 are not.

Try this: change the values to your own details, then add a $favouriteFood variable and print it.
