Lesson 01

Install WampServer

Goal

Get WampServer and VS Code installed on your PC.

Steps

  1. Go to the official site: wampserver.com/en.
  2. Download the 64-bit version (almost every modern PC is 64-bit).
  3. Run the installer and keep the default folder, C:\wamp64.
  4. If it asks which browser or text editor to use, the defaults are fine.
  5. If Windows says some Visual C++ Redistributable packages are missing, install them first (the WampServer site links to them), then run the installer again.
  6. Install Visual Studio Code. It colours your code and helps you spot mistakes.

You should have

A C:\wamp64 folder on your PC, and Wampserver64 and Visual Studio Code in your Start menu.

Check yourself: open File Explorer and go to C:\wamp64. Can you see a folder called www? Good, that's where your projects will live.
