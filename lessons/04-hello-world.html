Lesson 04

Hello World

Goal

Write your first proper PHP page. PHP code goes between <?php and ?>, and echo prints something onto the page.

Steps

  1. In C:\wamp64\www, create a folder called 04-hello-world.
  2. Inside it, create index.php and paste in the code below. Typing it yourself is even better.
  3. Save with Ctrl+S.
  4. Open http://localhost/04-hello-world/ in your browser.
Save asC:\wamp64\www\04-hello-world\index.php
Run ithttp://localhost/04-hello-world/
04-hello-world/index.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hello World</title>
</head>
<body>
    <h1><?php echo "Hello, World!"; ?></h1>
    <p>Today is <?php echo date("l, j F Y"); ?>.</p>
</body>
</html>

You should see

A big Hello, World! heading with today's date underneath.

Try this: change the message to greet you by name. Then add another line that shows the time using date("H:i").
