Lesson 02

Start it & check localhost

Goal

Start WampServer and confirm your PC is now running a web server.

Steps

  1. Open Wampserver64 from the Start menu.
  2. Look for a small W icon in the system tray, near the clock. You may need to click the ^ arrow to see it.
  3. Wait until the icon turns green:
    • Green: everything is running. You're ready.
    • Orange: only some services started. See Troubleshooting.
    • Red: nothing is running yet. Wait a few seconds, or see Troubleshooting.
  4. Open your browser and go to http://localhost.

You should see

The WampServer home page, which shows the versions of Apache, PHP and MySQL. That page comes from your own PC!

Check yourself: what does "localhost" mean? Answer: "this computer". Your browser is talking to the server running on your own PC.
