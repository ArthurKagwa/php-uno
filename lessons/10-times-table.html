Lesson 10

Loops: times table

Goal

Let PHP do the repetitive work. A for loop runs the same code many times, and here it builds 12 table rows.

Steps

  1. In C:\wamp64\www, create a folder called 10-times-table.
  2. Inside it, create index.php and paste in the code below. Typing it yourself is even better.
  3. Save with Ctrl+S.
  4. Open http://localhost/10-times-table/ in your browser.
Save asC:\wamp64\www\10-times-table\index.php
Run ithttp://localhost/10-times-table/
10-times-table/index.php
<?php
// Which times table to show
$n = 7;
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Multiplication Table</title>
</head>
<body>
    <h1>Times table for <?php echo $n; ?></h1>

    <table border="1" cellpadding="6">
        <?php for ($i = 1; $i <= 12; $i++): ?>
            <tr>
                <td><?php echo "$n × $i"; ?></td>
                <td><?php echo $n * $i; ?></td>
            </tr>
        <?php endfor; ?>
    </table>
</body>
</html>

You should see

A table running from 7 × 1 = 7 down to 7 × 12 = 84.

Reading the loop: for ($i = 1; $i <= 12; $i++) means: start $i at 1, keep going while it's 12 or less, and add 1 each time round.

Try this: change $n to 9, then make the table go up to 20.
