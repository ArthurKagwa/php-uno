Lesson 11

GET forms: greeting by time of day

Goal

Use a GET form. Unlike POST, what you type shows up in the address bar, like ?name=Arthur, and PHP reads it from $_GET. The page also says good morning, afternoon or evening depending on the time.

Steps

  1. In C:\wamp64\www, create a folder called 11-greeting.
  2. Inside it, create index.php and paste in the code below. Typing it yourself is even better.
  3. Save with Ctrl+S.
  4. Open http://localhost/11-greeting/ in your browser.
  5. Type your name and press Greet me. Then look at the address bar.
Save asC:\wamp64\www\11-greeting\index.php
Run ithttp://localhost/11-greeting/
11-greeting/index.php
<?php
// GET values show up in the URL, e.g. ?name=Arthur
$name = trim($_GET["name"] ?? "");
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Greeting</title>
</head>
<body>
    <h1>Greeting form</h1>

    <form method="get">
        <input type="text" name="name" placeholder="Your name"
               value="<?php echo htmlspecialchars($name); ?>">
        <button type="submit">Greet me</button>
    </form>

    <?php if ($name !== ""): ?>
        <?php
        $hour = (int) date("G");
        if ($hour < 12) {
            $greeting = "Good morning";
        } elseif ($hour < 17) {
            $greeting = "Good afternoon";
        } else {
            $greeting = "Good evening";
        }
        ?>
        <h2><?php echo $greeting . ", " . htmlspecialchars($name) . "!"; ?></h2>
    <?php endif; ?>
</body>
</html>

You should see

Something like "Good evening, Arthur!", and the address changes to …/11-greeting/?name=Arthur.

GET or POST? Use GET for things that are fine to share or bookmark, like searches. Use POST for things that change data or are private, like passwords.

Try this: type a different name straight into the address bar, e.g. ?name=Mum, and press Enter. Then add a box for a favourite colour and show the greeting in that colour. Don't forget htmlspecialchars()!
