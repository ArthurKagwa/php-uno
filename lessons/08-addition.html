Lesson 08

Your first form: add two numbers

Goal

Let the user type the numbers. An HTML form sends them back to the same page with POST, and PHP reads them from $_POST.

Steps

  1. In C:\wamp64\www, create a folder called 08-addition.
  2. Inside it, create index.php and paste in the code below. Typing it yourself is even better.
  3. Save with Ctrl+S.
  4. Open http://localhost/08-addition/ in your browser.
  5. Type two numbers and press Add.
Save asC:\wamp64\www\08-addition\index.php
Run ithttp://localhost/08-addition/
08-addition/index.php
<?php
$result = null;
$error = "";
$a = "";
$b = "";

// Only run this part after the form is submitted
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $a = trim($_POST["a"] ?? "");
    $b = trim($_POST["b"] ?? "");

    if ($a === "" || $b === "") {
        $error = "Please fill in both numbers.";
    } elseif (!is_numeric($a) || !is_numeric($b)) {
        $error = "Please type numbers only.";
    } else {
        $result = $a + $b;
    }
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Add Two Numbers</title>
</head>
<body>
    <h1>Add two numbers</h1>

    <form method="post">
        <input type="text" name="a" placeholder="First number"
               value="<?php echo htmlspecialchars($a); ?>">
        +
        <input type="text" name="b" placeholder="Second number"
               value="<?php echo htmlspecialchars($b); ?>">
        <button type="submit">Add</button>
    </form>

    <?php if ($error !== ""): ?>
        <p style="color: red;"><?php echo htmlspecialchars($error); ?></p>
    <?php elseif ($result !== null): ?>
        <h2>
            <?php echo htmlspecialchars($a) . " + " . htmlspecialchars($b) . " = " . $result; ?>
        </h2>
    <?php endif; ?>
</body>
</html>

You should see

Type 5 and 7 and you get "5 + 7 = 12". Leave a box empty, or type letters, and you get a red error message.

Two good habits:
1. Check the input before using it. is_numeric() makes sure it's a number.
2. Wrap anything the user typed in htmlspecialchars() before you show it. That stops people from injecting their own HTML into your page.
