Lesson 12

Troubleshooting

Goal

Fix the problems almost every beginner runs into. Tap a problem to see the fix.

The WampServer icon stays orange or red

Another program is probably using port 80, the port Apache needs. Common culprits are Skype, IIS (Windows' own web server) and other servers such as XAMPP.

  1. Close Skype, or turn off its use of port 80 in its settings.
  2. Turn off IIS: open Turn Windows features on or off, untick Internet Information Services, then restart.
  3. Check the port: left-click the tray icon → Apache → Service administration → Test port 80.
  4. Left-click the icon → Restart All Services.
My PHP code shows up as plain text

You opened the file directly, so the address starts with file:///C:/… and PHP never ran.

Fix: open it through http://localhost/your-folder/. Also check that the file ends in .php and not .php.txt. In File Explorer, go to View → File name extensions to see the real name.

404 Not Found

The server can't find the folder. Check that:

  • the folder is directly inside C:\wamp64\www;
  • the name in the address matches the folder name exactly (04-hello-world is not the same as hello-world);
  • the file is called index.php.
The page is completely blank

A PHP error happened, but error messages are switched off.

  1. Left-click the tray icon → PHP → PHP settings → tick display_errors, then refresh.
  2. Or, while you're learning, put this at the very top of your file:
index.php
<?php
ini_set('display_errors', 1);
error_reporting(E_ALL);
?>

Then look for the usual mistakes: a missing ;, a missing } or ), a missing $, or a missing closing quote.

Check yourself: break your Hello World on purpose by deleting a ;. Turn on display_errors and read the message. Which line number does it point to?
