Lesson 07

If / else decisions

Goal

Make your code decide. if runs some code only when a condition is true, and else runs otherwise.

Steps

  1. In C:\wamp64\www, create a folder called 07-even-odd.
  2. Inside it, create index.php and paste in the code below. Typing it yourself is even better.
  3. Save with Ctrl+S.
  4. Open http://localhost/07-even-odd/ in your browser.
  5. Change $number = 7; to another number, save, and refresh.
Save asC:\wamp64\www\07-even-odd\index.php
Run ithttp://localhost/07-even-odd/
07-even-odd/index.php
<?php
// Change this number, save, and refresh the page
$number = 7;

// % gives the remainder after dividing
if ($number % 2 == 0) {
    $answer = "EVEN";
} else {
    $answer = "ODD";
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Even or Odd</title>
</head>
<body>
    <h1>Even or odd?</h1>
    <p><?php echo "$number is $answer."; ?></p>

    <?php if ($number > 100): ?>
        <p>That's a big number!</p>
    <?php endif; ?>
</body>
</html>

You should see

"7 is ODD." Change the number to 8 and you get "8 is EVEN." Try 150 and you also get "That's a big number!"

Notice: == compares two values, while a single = sets a value. Mixing them up is a very common beginner mistake.

Try this: add an elseif that prints "zero" when the number is 0, and another check for negative numbers ($number < 0).
