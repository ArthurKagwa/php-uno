Lesson 06

Joining text & simple maths

Goal

Join pieces of text with the dot (.) and do maths with + - * / %.

Steps

  1. In C:\wamp64\www, create a folder called 06-text-and-maths.
  2. Inside it, create index.php and paste in the code below. Typing it yourself is even better.
  3. Save with Ctrl+S.
  4. Open http://localhost/06-text-and-maths/ in your browser.
Save asC:\wamp64\www\06-text-and-maths\index.php
Run ithttp://localhost/06-text-and-maths/
06-text-and-maths/index.php
<?php
$firstName = "Arthur";
$lastName = "Asasira";

// The dot (.) joins pieces of text together
$fullName = $firstName . " " . $lastName;

$price = 1500;
$quantity = 3;
$total = $price * $quantity;
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text &amp; Maths</title>
</head>
<body>
    <h1>Hello, <?php echo $fullName; ?>!</h1>

    <h2>Shopping</h2>
    <p><?php echo $quantity . " pens at " . $price . " each = " . $total; ?></p>

    <h2>Maths with 10 and 3</h2>
    <p>10 + 3 = <?php echo 10 + 3; ?></p>
    <p>10 - 3 = <?php echo 10 - 3; ?></p>
    <p>10 * 3 = <?php echo 10 * 3; ?></p>
    <p>10 / 3 = <?php echo round(10 / 3, 2); ?></p>
    <p>10 % 3 = <?php echo 10 % 3; ?> (the remainder)</p>
</body>
</html>

You should see

"Hello, Arthur Asasira!", then "3 pens at 1500 each = 4500", then the answers 13, 7, 30, 3.33 and 1.

Notice: * means times and / means divide. % gives the remainder: 10 ÷ 3 is 3 with 1 left over, so 10 % 3 is 1. You'll use that in the next lesson.

Check yourself: what is 17 % 5? Add a line that prints it to find out. (It should be 2.)
