# php-uno

Beginner PHP projects for **WampServer** on Windows, plus a phone-friendly guide that walks you through every step.

## View the guide

- **Online:** once GitHub Pages is turned on for this repo (*Settings → Pages → Deploy from branch → `main` / root*), the guide is at `https://<your-username>.github.io/php-uno/`.
- **Offline:** download the repo and open `index.html` in any browser.

## What's inside

```
php-uno/
├── index.html          # the guide (setup, projects, troubleshooting)
├── assets/             # styles and a small script (menu + copy buttons)
└── projects/           # ready-to-run PHP projects
    ├── hello-world/    # 1. first PHP page with echo
    ├── variables/      # 2. variables, strings and echo
    ├── addition/       # 3. add two numbers with a POST form
    ├── calculator/     # 4. + − × ÷ calculator with divide-by-zero check
    ├── even-odd/       # 5. even or odd checker
    ├── times-table/    # 6. multiplication table with a for loop
    └── greeting/       # 7. greeting form using GET
```

## Run the projects

1. Install [WampServer](https://www.wampserver.com/en/) and start it (wait for the green tray icon).
2. Copy the folders inside `projects/` into `C:\wamp64\www`.
3. Open them in your browser, e.g. `http://localhost/hello-world/` or `http://localhost/calculator/`.

Using XAMPP? It works the same way. Just copy the folders into `C:\xampp\htdocs` instead.
