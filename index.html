Your first PHP projects, step by step

This guide shows you how to run PHP on your own Windows PC with WampServer. You'll set everything up once, then build 7 small projects, starting with Hello World and working up to a calculator.

Start here → Jump to projects

Using XAMPP instead? Everything here works the same way. Just put your folders in C:\xampp\htdocs instead of C:\wamp64\www.

Step 1

Set up WampServer

WampServer bundles Apache (the web server), PHP and MySQL into one install, so your PC can run PHP pages.

  1. Download it. Go to the official site, wampserver.com/en, and download the 64-bit version.
  2. Install it. Run the installer and keep the default folder, C:\wamp64. If it asks for a browser or text editor, the defaults are fine. If Windows says some "Visual C++ Redistributable" packages are missing, install them first (the WampServer site links to them), then try again.
  3. Start it. Open Wampserver64 from the Start menu. A small "W" icon shows up in the system tray, near the clock. You may need to click the ^ arrow to see it.
  4. Check the icon colour.
    • Green: everything is running. You're ready.
    • Orange: only some services started. See Troubleshooting.
    • Red: nothing is running yet. Wait a few seconds, or see Troubleshooting.
  5. Test it. Open your browser and go to http://localhost. If you see the WampServer home page, it works.
  6. Find the www folder. All your projects live in C:\wamp64\www. You can also left-click the tray icon and choose www directory.
  7. Get a code editor. Install Visual Studio Code (free). It colours your code and helps you spot mistakes. Notepad works too, but VS Code is much nicer.
Step 2

How to make a project

Every project follows the same 3 steps:

  1. In C:\wamp64\www, create a new folder, for example hello-world. Use lowercase letters and dashes, with no spaces.
  2. In VS Code, open that folder (File → Open Folder), create a file called index.php, paste in your code and save it (Ctrl+S).
  3. In your browser, open http://localhost/hello-world/. The folder name goes after localhost/.

Important: always open PHP pages through http://localhost/…. Double-clicking the file won't work, because then the browser opens the file directly and PHP never runs.

After you change the code, save the file and refresh the browser (F5) to see the result.

Shortcut: every project below is also in the projects/ folder of this repo. Download the repo (Code → Download ZIP on GitHub), unzip it, and copy the folders inside projects/ into C:\wamp64\www. Typing the code yourself is the better way to learn, though!

Project 1

Hello World

Your very first PHP page. PHP code goes between <?php and ?>, and echo prints text onto the page.

Save asC:\wamp64\www\hello-world\index.php
Openhttp://localhost/hello-world/
hello-world/index.php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hello World</title>
</head>
<body>
    <h1><?php echo "Hello, World!"; ?></h1>
    <p>Today is <?php echo date("l, j F Y"); ?>.</p>
</body>
</html>

You should see: a big "Hello, World!" heading and today's date underneath.

Try this: change the message to say hello to you by name, then add a second echo that prints the current time using date("H:i").

Project 2

Variables & echo

A variable is a labelled box that stores a value. In PHP, variable names start with $. Inside double quotes, PHP swaps a variable for its value, and a dot (.) joins pieces of text together.

Save asC:\wamp64\www\variables\index.php
Openhttp://localhost/variables/
variables/index.php
<?php
// Variables start with a $ sign
$name = "Arthur";
$age = 23;
$city = "Kampala";
$likesCoding = true;
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Variables &amp; echo</title>
</head>
<body>
    <h1>About me</h1>
    <?php
    echo "<p>My name is $name.</p>";
    echo "<p>I am " . $age . " years old.</p>";
    echo "<p>I live in $city.</p>";

    if ($likesCoding) {
        echo "<p>I like coding!</p>";
    }

    $nextYear = $age + 1;
    echo "<p>Next year I will be $nextYear.</p>";
    ?>
</body>
</html>

You should see: 5 lines about "Arthur", including "Next year I will be 24."

Try this: change the values to your own details, then add a $favouriteFood variable and print it.

Project 3

Add two numbers (form + POST)

Now the user gives the page some input. An HTML form sends the two numbers back to the same page with POST, and PHP reads them from $_POST. The code checks that both boxes contain numbers, and it uses htmlspecialchars() before showing anything the user typed, which keeps the page safe.

Save asC:\wamp64\www\addition\index.php
Openhttp://localhost/addition/
addition/index.php
<?php
$result = null;
$error = "";
$a = "";
$b = "";

// Only run this part after the form is submitted
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $a = trim($_POST["a"] ?? "");
    $b = trim($_POST["b"] ?? "");

    if ($a === "" || $b === "") {
        $error = "Please fill in both numbers.";
    } elseif (!is_numeric($a) || !is_numeric($b)) {
        $error = "Please type numbers only.";
    } else {
        $result = $a + $b;
    }
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Add Two Numbers</title>
</head>
<body>
    <h1>Add two numbers</h1>

    <form method="post">
        <input type="text" name="a" placeholder="First number"
               value="<?php echo htmlspecialchars($a); ?>">
        +
        <input type="text" name="b" placeholder="Second number"
               value="<?php echo htmlspecialchars($b); ?>">
        <button type="submit">Add</button>
    </form>

    <?php if ($error !== ""): ?>
        <p style="color: red;"><?php echo htmlspecialchars($error); ?></p>
    <?php elseif ($result !== null): ?>
        <h2>
            <?php echo htmlspecialchars($a) . " + " . htmlspecialchars($b) . " = " . $result; ?>
        </h2>
    <?php endif; ?>
</body>
</html>

You should see: two boxes and an Add button. Type 5 and 7 and you get "5 + 7 = 12". Leave a box empty, or type letters, and you get a red error message.

Try this: add a third input box and add all three numbers together.

Project 4

Simple calculator (+ − × ÷)

This builds on Project 3. A dropdown picks the operation, and a switch statement does the right sum. It also stops you from dividing by zero.

Save asC:\wamp64\www\calculator\index.php
Openhttp://localhost/calculator/
calculator/index.php
<?php
$result = null;
$error = "";
$a = "";
$b = "";
$op = "+";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $a = trim($_POST["a"] ?? "");
    $b = trim($_POST["b"] ?? "");
    $op = $_POST["op"] ?? "+";

    if (!is_numeric($a) || !is_numeric($b)) {
        $error = "Please type two numbers.";
    } else {
        switch ($op) {
            case "+":
                $result = $a + $b;
                break;
            case "-":
                $result = $a - $b;
                break;
            case "*":
                $result = $a * $b;
                break;
            case "/":
                if ($b == 0) {
                    $error = "You cannot divide by zero.";
                } else {
                    $result = $a / $b;
                }
                break;
            default:
                $error = "Unknown operation.";
        }
    }
}

// Symbols to show on the page
$symbols = ["+" => "+", "-" => "−", "*" => "×", "/" => "÷"];
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Simple Calculator</title>
</head>
<body>
    <h1>Simple calculator</h1>

    <form method="post">
        <input type="text" name="a" value="<?php echo htmlspecialchars($a); ?>">
        <select name="op">
            <?php foreach ($symbols as $value => $label): ?>
                <option value="<?php echo $value; ?>" <?php if ($op === $value) echo "selected"; ?>>
                    <?php echo $label; ?>
                </option>
            <?php endforeach; ?>
        </select>
        <input type="text" name="b" value="<?php echo htmlspecialchars($b); ?>">
        <button type="submit">=</button>
    </form>

    <?php if ($error !== ""): ?>
        <p style="color: red;"><?php echo htmlspecialchars($error); ?></p>
    <?php elseif ($result !== null): ?>
        <h2>Answer: <?php echo round($result, 4); ?></h2>
    <?php endif; ?>
</body>
</html>

You should see: 10 × 4 gives "Answer: 40", and 10 ÷ 0 gives "You cannot divide by zero."

Try this: add a % (remainder) option to the dropdown and a matching case in the switch.

Project 5

Even or odd checker

The % operator gives the remainder after dividing. If a number divided by 2 leaves 0, it's even. Otherwise it's odd. This project uses if / elseif / else to decide.

Save asC:\wamp64\www\even-odd\index.php
Openhttp://localhost/even-odd/
even-odd/index.php
<?php
$message = "";
$number = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $number = trim($_POST["number"] ?? "");

    // Only whole numbers can be even or odd
    if (filter_var($number, FILTER_VALIDATE_INT) === false) {
        $message = "Please type a whole number, like 7 or 12.";
    } elseif ($number % 2 === 0) {
        $message = "$number is EVEN.";
    } else {
        $message = "$number is ODD.";
    }
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Even or Odd</title>
</head>
<body>
    <h1>Even or odd?</h1>

    <form method="post">
        <input type="text" name="number" placeholder="Type a number"
               value="<?php echo htmlspecialchars($number); ?>">
        <button type="submit">Check</button>
    </form>

    <?php if ($message !== ""): ?>
        <h2><?php echo htmlspecialchars($message); ?></h2>
    <?php endif; ?>
</body>
</html>

You should see: 8 gives "8 is EVEN." and 13 gives "13 is ODD." Typing 2.5 or "abc" asks for a whole number.

Try this: also say whether the number is positive, negative or zero.

Project 6

Multiplication table (loop)

A for loop repeats code. This one runs 12 times and builds one table row each time. The number comes from the URL, as ?n=.

Save asC:\wamp64\www\times-table\index.php
Openhttp://localhost/times-table/
times-table/index.php
<?php
// Read ?n= from the URL, default to 7
$n = filter_var($_GET["n"] ?? 7, FILTER_VALIDATE_INT);
if ($n === false) {
    $n = 7;
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Multiplication Table</title>
</head>
<body>
    <h1>Times table for <?php echo $n; ?></h1>

    <form method="get">
        <input type="number" name="n" value="<?php echo $n; ?>">
        <button type="submit">Show</button>
    </form>

    <table border="1" cellpadding="6">
        <?php for ($i = 1; $i <= 12; $i++): ?>
            <tr>
                <td><?php echo "$n × $i"; ?></td>
                <td><?php echo $n * $i; ?></td>
            </tr>
        <?php endfor; ?>
    </table>
</body>
</html>

You should see: the 7 times table from 7 × 1 to 7 × 12. Type 9 and press Show, or open http://localhost/times-table/?n=9.

Try this: make the table go up to 20, or add a second box that sets how many rows to show.

Project 7

Greeting form (GET)

This form uses GET instead of POST, so whatever you type shows up in the address bar, like ?name=Arthur. PHP reads it from $_GET. The page also picks morning, afternoon or evening based on the time.

Save asC:\wamp64\www\greeting\index.php
Openhttp://localhost/greeting/
greeting/index.php
<?php
// GET values show up in the URL, e.g. ?name=Arthur
$name = trim($_GET["name"] ?? "");
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Greeting</title>
</head>
<body>
    <h1>Greeting form</h1>

    <form method="get">
        <input type="text" name="name" placeholder="Your name"
               value="<?php echo htmlspecialchars($name); ?>">
        <button type="submit">Greet me</button>
    </form>

    <?php if ($name !== ""): ?>
        <?php
        $hour = (int) date("G");
        if ($hour < 12) {
            $greeting = "Good morning";
        } elseif ($hour < 17) {
            $greeting = "Good afternoon";
        } else {
            $greeting = "Good evening";
        }
        ?>
        <h2><?php echo $greeting . ", " . htmlspecialchars($name) . "!"; ?></h2>
    <?php endif; ?>
</body>
</html>

You should see: type your name and you get something like "Good evening, Arthur!", and the URL changes to …/greeting/?name=Arthur.

Try this: add a second box for a favourite colour and show the greeting in that colour. Remember to use htmlspecialchars()!

Step 4

Troubleshooting

Stuck? Tap a problem to see the fix.

The WampServer icon stays orange or red

Usually another program is already using port 80, the port Apache needs. Common culprits are Skype, IIS (Windows' own web server) and other servers such as XAMPP.

  1. Close Skype, or in its settings turn off using port 80.
  2. Turn off IIS: open Turn Windows features on or off, untick Internet Information Services, then restart.
  3. Check the port: left-click the tray icon → Apache → Service administration → Test port 80. It tells you what's using it.
  4. Then left-click the icon and choose Restart All Services.
My PHP code shows up as plain text

You opened the file directly, and the address bar shows something like file:///C:/wamp64/www/…. The browser is just displaying the file, and PHP never runs it.

Fix: open it through the server instead, at http://localhost/your-folder/. Also make sure the file ends in .php and not .php.txt. In File Explorer, go to View → File name extensions to check.

404 Not Found

The server can't find the folder you asked for. Check that:

  • the folder is directly inside C:\wamp64\www, not in a folder inside another folder;
  • the name in the URL matches the folder name exactly (hello-world is not the same as helloworld or Hello World);
  • the file is called index.php. If it has a different name, add it to the URL, e.g. http://localhost/hello-world/test.php.
The page is completely blank

A blank page usually means a PHP error happened, but the error messages are switched off.

  1. Turn errors on: left-click the tray icon → PHP → PHP settings → tick display_errors. Then refresh the page.
  2. Or put this at the very top of your file, while you're learning:
index.php
<?php
ini_set('display_errors', 1);
error_reporting(E_ALL);
?>

Then look for the usual mistakes: a missing ; at the end of a line, a missing } or ), a missing $ before a variable, or a missing closing quote.
